# Транслятор Go в Python

## Структура проекта

- `app/` - основная папка приложения
  - `main.py` - точка входа для запуска транслятора
- `lexer/` - лексер (токенизатор)
  - `tokenizer.py` - класс токенизатора Go
  - `tokens.py` - определения токенов
- `parser/` - парсер
  - `go_parser.py` - парсер Go кода
  - `ast_nodes.py` - определения узлов AST
- `translator/` - транслятор
  - `python_emitter.py` - эмиттер Python кода
- `tests/` - тестовые файлы
  - `test.go`, `test2.go`, `test3.go` - примеры Go кода для тестирования
  - `test_*.py` - unit-тесты для компонентов

## Установка

1. Клонируйте репозиторий.
2. Установите зависимости с помощью uv или pip:
   ```
   uv sync
   ```
   или
   ```
   pip install -e .
   ```

## Использование

Запустите транслятор с помощью команды:

```
python app/main.py
```

Это запустит обработку трех тестовых файлов (`tests/test.go`, `tests/test2.go`, `tests/test3.go`) и сохранит результаты трансляции в файлы `output.py`, `output2.py`, `output3.py` соответственно.

Транслятор выполняет следующие этапы:
1. Токенизация - разбор исходного кода на токены
2. Парсинг - построение AST (абстрактного синтаксического дерева)
3. Трансляция - генерация Python кода из AST

Для обработки других файлов Go вы можете модифицировать `app/main.py`, добавив вызовы функции `process_file` с путями к вашим файлам.

## Тестирование

Запустите тесты с помощью:

```
pytest
```

Тесты проверяют корректность работы лексера, парсера и транслятора.
